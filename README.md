# 📚 School Library Management API

A RESTful API built with Node.js, Express, and MongoDB for managing a school library system.

---

## 🚀 Tech Stack
- Node.js
- Express.js
- MongoDB (Mongoose)
- Postman (for testing)

---

## 📦 Features

### 👤 Users
- Students can be created and managed
- Library Attendants manage book issuance

### 📚 Books
- Create, update, delete books
- Assign multiple authors
- Track availability (IN / OUT)

### 🔄 Borrowing System
- Borrow books with student + attendant
- Return books
- Track due dates

### 🔍 Advanced Features
- Search books by title
- Filter by author
- Pagination support
- Populate relations (authors, students, attendants)
